### 📌 Yêu cầu hệ thống / Prerequisites

* **Android OS:** 8.0+
* **Root:** Magisk / KernelSU / APatch
* **Framework:** LSPosed (Đã kích hoạt)

---

## 🇻🇳 Hướng dẫn cài đặt

1. **Tải về:** Truy cập mục **[Releases](../../releases)** để tải file `.apk` mới nhất.
2. **Cài đặt:** Mở file và tiến hành cài đặt ứng dụng.
3. **Kích hoạt Module:**
   * Mở ứng dụng **LSPosed**.
   * Mục **Modules** ➔ Tìm và bật **Fake GPS**.
   * Tích chọn danh sách các ứng dụng bạn muốn giả lập vị trí.
4. **Khởi động lại:** Khởi động lại thiết bị để kích hoạt hook cấp hệ thống.
5. **Video Hướng Dẫn:** 🎬 [Xem từng bước trên YouTube](https://youtu.be/26nd7CD_Erc)

## 🇬🇧 Installation Guide

1. **Download:** Go to **[Releases](../../releases)** and download the latest `.apk`.
2. **Install:** Install the APK file on your device.
3. **Enable Module:**
   * Open the **LSPosed** manager.
   * Go to **Modules** ➔ Enable **Fake GPS**.
   * Check the target applications you want to spoof location for.
4. **Reboot:** Restart your device to apply system hooks.
5. **Video Guide:** 🎬 [Watch tutorial on YouTube](https://youtu.be/26nd7CD_Erc)
